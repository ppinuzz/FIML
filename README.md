# Field Inversion and Machine Learning (FIML) #

Create the `FIML` enviroment:
```
mamba create --name FIML python=3.13.2 numpy=2.2.4 matplotlib=3.10.1 prettytable=3.16.0 scipy=1.15.2 colorama=0.4.6 pyyaml=6.0.2 pandas=3.0.6 spyder-kernels=3.0
```
Install JAX separately with
```
pip install -U jax
```
